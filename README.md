# QRs Code

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript e funciona diretamente da pasta do projeto.

Escolha **Link** ou **Texto**, ajuste a aparência e clique em **Gerar QR Code**. Cores, estilo, tamanho e correção de erros também podem ser ajustados com o QR já gerado. Escolha PNG, JPG ou PDF e clique em **Baixar QR Code**. O tamanho selecionado define a resolução da imagem, inclusive da imagem incorporada ao PDF.

## API

O botão de geração envia o conteúdo e as opções do QR Code à API pública do QuickChart. O site usa a biblioteca Nayuki para a prévia inicial, para alterações de aparência e como alternativa quando a API estiver indisponível.

- [Documentação da API do QuickChart](https://quickchart.io/documentation/qr-codes/)
- [Biblioteca QR Code Generator de Project Nayuki](https://www.nayuki.io/page/qr-code-generator-library)
